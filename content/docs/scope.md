# Scope

RELL covers **Robinhood Chain + Stock Tokens**.

## What's Built

1. Asset search
2. Token lookup
3. RELL profile page
4. Rights matrix (the six categories)
5. Source / document references
6. Onchain verification
7. Plain-English explanations
8. Last-updated timestamp

## Why This Scope

Stock tokens on Robinhood Chain are a single, well-documented asset class — enough to fully exercise the rights-matrix concept, the verification labeling, and the conflict-resolution logic in one coherent product.

## Out of Scope

- Other chains
- Non-stock RWA categories
- Any of the items listed in [What RELL Is Not](non-goals.md)
